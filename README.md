# 麦生活 · 周期日历 1.2.0

MaiBot 的独立角色模拟扩展，依赖 [麦生活（Mai_life）](https://github.com/octmicy/Mai_life) `>=1.26.6,<2`。
通过 `config.get_plugin` 只读访问麦生活的 `state`、`environment.timezone` 和 `users.profiles`，不修改麦生活源码、配置、日程或状态数值。角色上下文由本扩展自己的钩子注入。

> 本项目用于虚构角色模拟。日历估算不能用于避孕；模拟槽分配、衰减、双卵概率和妊娠触发概率都是人为游戏参数，不是生理测量、医学诊断或真实受孕概率。

项目地址：[joshuapex/mailife-cycle-journal](https://github.com/joshuapex/mailife-cycle-journal)。许可证：MIT。

## 安装

1. 在 MaiBot 中安装并启用麦生活 `>=1.26.6,<2`。本插件声明支持 MaiBot `1.3.18～1.4.99`、SDK `2.19.0～2.91.99`；实际可用性以宿主的清单校验为准。
2. 克隆本仓库，或在 GitHub 的 **Code → Download ZIP** 下载源码。插件清单 `_manifest.json` 位于仓库根目录，可将下载的 ZIP 交给 MaiBot 的扩展集成安装。
3. 若宿主未立即加载新插件，在扩展集成中重新启用该插件，必要时重启插件运行环境。
4. 打开侧栏的 **周期日历**；周期起始日期等沿用麦生活设置，模拟参数在本扩展配置页调整。

仓库中的 `config.toml` 是不含用户ID或凭据的出厂默认配置。升级时保留自己的配置和 SDK 数据目录，不要用出厂配置覆盖已有设置。

## 页面与配置

侧栏“周期日历”展示分层周期时间轴、逐日网格、阶段日期表，以及私聊自述事件和虚构角色模拟。
周期起始日期、长度和经期天数沿用麦生活设置。未填写起始日期、关闭周期或日期无效时，明确提示并可手动查看示意，不伪造当前状态。

本扩展配置中的“角色模拟与事件”提供每次模拟射出量、两个模拟槽分配比例、半衰期、双卵概率、私聊捕获开关和用户ID白名单。两槽比例之和必须≤1；配置变更仅影响新事件。

## 性行为历史记录

独立历史区支持按日期范围、事件类型、记录来源筛选，每页20条，无“最近200条”的历史访问限制；按自述发生日期倒序排列，晚补记的旧事件仍落在相应日期。记录跨周期保存，重启不清空。

类型区分已避孕、无保护但未明确内射、明确内射、发生过但方式未说明。只有明确内射才注入虚构模拟槽，其他类型不推定内射。每条详情展示自述时间与精度、登记时间、来源、按当前麦生活配置回算的阶段、当次模拟量/比例/半衰期，以及当前该事件的模拟贡献。错误记录可删除；复杂语句或漏记可以手动补记。不会扫描安装前的聊天推断历史。

## 虚构妊娠与上下文

默认启用：新记录的明确内射事件发生在估算易孕窗口内，且事件在最近7天内（可配置0～30天）时，以配置概率（默认20%，纯游戏参数，非真实受孕率）抽样一次。更早的补记仅存历史，不改变当前剧情。结果按事件持久化，刷新、重启或改概率不会重抽。已在妊娠/产后模拟中时，不再开始另一条。旧历史不回溯抽样，模拟留存槽的量不影响概率。

通过新私聊事件触发妊娠抽样默认仅允许麦生活已启用的owner，或另行指定触发QQ用户ID。其他用户的自述可以按事件捕获设置保留为历史，但不会改变当前妊娠剧情。管理员手动补记视为明确的角色设定操作。

组件显示模拟孕周、早/中/晚阶段、模拟预计日期、胎数、角色状态备注和妊娠历史。自动触发默认单胎，孕周起算日采用事件所属周期首日；手动覆盖可指定1或2胎、起算日和备注。预计日期按起算日+280天约定，14周/28周分段；不自动制造检查结果、疾病或分娩。管理员可结算分娩剧情进入产后模拟，或直接结束；覆盖与结束均保留历史。删除触发事件不会自动结束妊娠，需单独操作。妊娠/产后期间暂停本组件常规排卵图，麦生活原始配置和状态数值不改动；结束后恢复原周期展示，不重置源周期日期。

授权QQ私聊的Planner和Replyer获得简短的“虚构角色妊娠状态”上下文，包含阶段、模拟孕周/预计日期、胎数和角色备注；不注入性行为历史、参与者或模拟留存量。默认只允许麦生活中已启用的owner，或在扩展配置中指定QQ用户ID。群聊不注入；重启后在新私聊入站建立可信会话身份后才注入。结束后会注入结束状态以避免沿用旧设定。备注作为状态数据引用，不作为指令。可关闭上下文注入。

阶段/日期约定参考 [ACOG孕周说明](https://www.acog.org/womens-health/faqs/how-your-fetus-grows-during-pregnancy) 和 [预计日期说明](https://www.acog.org/clinical/clinical-guidance/committee-opinion/articles/2017/05/methods-for-estimating-the-due-date)；它们不支持本插件的虚构触发概率或其他游戏参数。

## 三类信息严格区分

- 周期估算：排卵日为周期第 `长度−14` 天；易孕窗口为该日前5天至后1天（包含端点）。经期作为独立叠加层，不视为“安全期”。这些日期不能用于避孕。
- 自述记录：用文本规则匹配私聊第一人称、明确已发生的性行为，区分已避孕、无保护、明确内射或方式未说明；不调用LLM判定。疑问、假设、否定、引用、群聊、复杂历史时间均忽略。复杂陈述可在页面补记，不保证所有自然语言都能识别。一条消息最多一条记录，不猜测行为次数。用户自述不等于已核实事实。
- 虚构模拟：只有明确内射才注入模拟槽。各槽 `配置量×当次比例×2^(−小时数/当次半衰期)`，多个事件累加。这些比例和衰减参数纯属人为游戏设置，无生理学依据；不是实际精液留存量、精子数、存活时间、受孕判断或医学建议。

仅自述日期的事件没有精确发生时刻；当天从记录时刻、往日从该日00:00启动虚构衰减。手动补记可明确时间。页面标注这个约定。

本周期模拟排卵数在1或2之间抽取。双卵概率默认5%，是纯虚构演示参数，不是人群发生率；设为0即固定单卵。每个周期首次查看时抽取一次并持久化，刷新、重启或修改概率不会重抽已有周期。当天模拟释放数只在估算排卵日显示，不模拟卵巢储备或真实卵子存活。

## 数据保存

事件、周期抽样和妊娠状态存入 SDK 分配的数据目录 `cycle_events.sqlite3`。事件不保存聊天原文、账号原值或昵称，仅保存参与者哈希摘要、日期、类型、去重摘要和当次配置快照。哈希摘要不等于不可逆匿名化，SQLite也不是加密存储；请妥善保护运行数据。管理员页面可删除事件及其模拟贡献。模拟槽合计包含所有已记录用户；建议配置白名单限制参与角色模拟的私聊用户。插件不主动请求外网、不发送聊天消息、不回溯旧聊天；授权状态上下文会进入宿主所配置的LLM请求。

## 开发与验证

源码结构：`cycle.py`负责周期日期，`events.py`负责自述规则、历史与模拟槽，`pregnancy.py`负责虚构妊娠生命周期，`plugin.py`适配宿主API与上下文钩子，`webui/index.html`为管理页面。

完整测试需使用装有当前 MaiBot SDK 的运行环境：

```bash
python -m unittest discover -s tests -v
```

未安装SDK时可单独执行纯逻辑测试：

```bash
python -m unittest discover -s tests -p test_cycle.py -v
python -m unittest discover -s tests -p test_pregnancy.py -v
```

Windows环境若缺少IANA时区数据，需要在开发虚拟环境中安装 `tzdata`。当前版本在实际宿主中通过27项后端测试及WebUI清单校验，并验证了桌面/手机页面交互。测试使用临时数据库，不依赖或分发真实聊天记录、NAS配置或运行数据。

资料：[ACOG](https://www.acog.org/womens-health/faqs/fertility-awareness-based-methods-of-family-planning)、[NHS](https://www.nhs.uk/conditions/periods/fertility-in-the-menstrual-cycle/)。资料支持周期常识，不支持任何虚构模拟槽的参数。

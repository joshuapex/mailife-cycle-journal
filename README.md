# 麦生活 · 周期日历 1.4.0

MaiBot 的独立角色状态扩展，依赖 [麦生活（Mai_life）](https://github.com/octmicy/Mai_life) `>=1.26.6,<2`。
通过 `config.get_plugin` 只读访问麦生活的 `state`、`environment.timezone` 和 `users.profiles`，不修改麦生活源码、配置、日程或状态数值。角色上下文由本扩展自己的钩子注入。

> 本项目用于角色状态管理。日历估算不能用于避孕；留存模型分配、衰减、双卵概率和妊娠触发概率都是人为游戏参数，不是生理测量、医学诊断或真实受孕概率。

项目地址：[joshuapex/mailife-cycle-journal](https://github.com/joshuapex/mailife-cycle-journal)。许可证：MIT。

## 安装

1. 在 MaiBot 中安装并启用麦生活 `>=1.26.6,<2`。本插件声明支持 MaiBot `1.3.18～1.4.99`、SDK `2.19.0～2.91.99`；实际可用性以宿主的清单校验为准。
2. 克隆本仓库，或在 GitHub 的 **Code → Download ZIP** 下载源码。插件清单 `_manifest.json` 位于仓库根目录，可将下载的 ZIP 交给 MaiBot 的扩展集成安装。
3. 若宿主未立即加载新插件，在扩展集成中重新启用该插件，必要时重启插件运行环境。
4. 打开侧栏的 **周期日历**；周期起始日期等沿用麦生活设置，模型参数在本扩展配置页调整。

仓库中的 `config.toml` 是不含用户ID或凭据的出厂默认配置。升级时保留自己的配置和 SDK 数据目录，不要用出厂配置覆盖已有设置。

## 页面与配置

页面按周期日历、身体状态、性行为历史、妊娠状态、设置与说明五个标签分类。支持键盘方向键切换；刷新数据保持当前分类，详细计算口径集中在设置与说明中。

侧栏“周期日历”展示分层周期时间轴、逐日网格、阶段日期表，以及私聊自述事件和角色状态管理。
周期起始日期、长度和经期天数沿用麦生活设置。未填写起始日期、关闭周期或日期无效时，明确提示并可手动查看示意，不伪造当前状态。

本扩展配置中的“身体状态与事件”提供每次射出量配置、两个留存模型分配比例、半衰期、双卵概率、私聊捕获开关和用户ID白名单。两槽比例之和必须≤1；配置变更仅影响新事件。

## 性行为历史记录

独立历史区支持按日期范围、事件类型、记录来源筛选，每页20条，无“最近200条”的历史访问限制；按自述发生日期倒序排列，晚补记的旧事件仍落在相应日期。记录跨周期保存，重启不清空。

类型区分已避孕、无保护但未明确内射、明确内射、发生过但方式未说明。只有明确内射才注入留存模型，其他类型不推定内射。每条详情展示自述时间与精度、登记时间、来源、按当前麦生活配置回算的阶段、当次配置量/比例/半衰期，以及当前该事件的模型计算贡献。错误记录可删除；复杂语句或漏记可以手动补记。不会扫描安装前的聊天推断历史。

## 上下文事件识别（1.4.0）

- 默认后台使用宿主的 planner 模型任务，context_task_name 可指定其他任务；每条相关用户消息至多分析一次，单次25秒超时，不阻塞QQ收发。模型失败、无效结果、队列溢出不会猜测完成事件。
- 同一QQ私聊保留最近16条、30分钟内的消息，每条至多1000字；超长、引用、通知及群消息不纳入分析，最多128个会话。原文仅在内存中短暂保留。重启、配置变更清空上下文，插件卸载取消并等待后台任务；不扫描既有聊天。
- 成功发送的机器人消息仅在之后用户发言时辅助判断，不触发分析，也不能单独作为完成证据。意图和进行中的消息保留为待确认诊断，之后用户确认完成才形成事件。
- 模型返回结构化状态、日期、类型、已有事件编号和用户证据索引；程序验证字段、证据来源、未来日期和跨会话编号，拒绝机器人单方完成、过期证据和明显假设。
- 同一事件通过持久化编号补充类型，分段/事后讨论不增加次数。合并窗口内只有用户明确新一轮的证据才新增第二条；归属不明确时保留诊断。此规则可能漏记省略语，需要时手动补记。
- 历史来源增加“聊天推断”，保留“用户自述”“管理员补记”。详情支持纠正日期和类型；人工纠正后的记录不再被模型覆盖。删除保留不含正文的去重墓碑，窗口内不自动复活。
- 历史页“近期识别诊断”展示新增、补充、重复、待确认、模型失败等原因及时间，不展示消息原文、消息ID或QQ号。诊断不等同于待办审批列表；不明确的事件可继续聊天确认，或由管理员补记。
- 类型补充为明确内射时沿用同一事件标识进行一次角色妊娠抽样；重试不重抽。人工纠正不触发新抽样，不自动撤销既有妊娠状态。过去历史不会自动补录。
- 新增的数据库表和字段兼容旧事件；降级旧版本前应备份数据库，因为旧界面不认识新增来源。

## 妊娠状态与上下文

默认启用：新记录的明确内射事件发生在估算易孕窗口内，且事件在最近7天内（可配置0～30天）时，以配置概率（默认20%，纯游戏参数，非真实受孕率）抽样一次。更早的补记仅存历史，不改变当前剧情。结果按事件持久化，刷新、重启或改概率不会重抽。已在妊娠/产后状态中时，不再开始另一条。旧历史不回溯抽样，模型计算留存槽的量不影响概率。

通过新私聊事件触发妊娠抽样默认仅允许麦生活已启用的owner，或另行指定触发QQ用户ID。其他用户的自述可以按事件捕获设置保留为历史，但不会改变当前妊娠剧情。管理员手动补记视为明确的角色设定操作。

组件显示孕周、早/中/晚阶段、预计分娩日期、胎数、角色状态备注和妊娠历史。自动触发默认单胎，孕周起算日采用事件所属周期首日；手动覆盖可指定1或2胎、起算日和备注。预计日期按起算日+280天约定，14周/28周分段；不自动制造检查结果、疾病或分娩。管理员可登记分娩进入产后阶段，或直接结束；覆盖与结束均保留历史。删除触发事件不会自动结束妊娠，需单独操作。妊娠/产后期间暂停本组件常规排卵图，麦生活原始配置和状态数值不改动；结束后恢复原周期展示，不重置源周期日期。

授权QQ私聊的Planner和Replyer获得简短的“角色妊娠状态”上下文，包含阶段、孕周/预计日期、胎数和角色备注；不注入性行为历史、参与者或模型计算留存量。默认只允许麦生活中已启用的owner，或在扩展配置中指定QQ用户ID。群聊不注入；重启后在新私聊入站建立可信会话身份后才注入。结束后会注入结束状态以避免沿用旧设定。备注作为状态数据引用，不作为指令。可关闭上下文注入。

阶段/日期约定参考 [ACOG孕周说明](https://www.acog.org/womens-health/faqs/how-your-fetus-grows-during-pregnancy) 和 [预计日期说明](https://www.acog.org/clinical/clinical-guidance/committee-opinion/articles/2017/05/methods-for-estimating-the-due-date)；它们不支持本插件的配置触发概率或其他游戏参数。

## 三类信息严格区分

- 周期估算：排卵日为周期第 `长度−14` 天；易孕窗口为该日前5天至后1天（包含端点）。经期作为独立叠加层，不视为“安全期”。这些日期不能用于避孕。
- 事件记录：默认使用宿主模型任务结合近期私聊识别已完成的角色事件。机器人消息仅作上下文，必须有用户证据；意图、进行中、疑问、假设、第三方和不确定日期不自动记为完成。关闭 context_capture_enabled 可恢复旧版单消息自述规则。聊天推断不等于已核实事实。
- 数值模型：只有明确内射才注入留存模型。各槽 `配置量×当次比例×2^(−小时数/当次半衰期)`，多个事件累加。这些比例和衰减参数纯属人为游戏设置，无生理学依据；不是实际精液留存量、精子数、存活时间、受孕判断或医学建议。

仅自述日期的事件没有精确发生时刻；当天从记录时刻、往日从该日00:00启动角色设定衰减。手动补记可明确时间。页面标注这个约定。

本周期排卵数（设定）在1或2之间抽取。双卵概率默认5%，是人为设定参数，不是人群发生率；设为0即固定单卵。每个周期首次查看时抽取一次并持久化，刷新、重启或修改概率不会重抽已有周期。当天预计释放数只在估算排卵日显示，不推断卵巢储备或真实卵子存活。

## 数据保存

事件、周期抽样和妊娠状态存入 SDK 分配的数据目录 `cycle_events.sqlite3`。事件不保存聊天原文、账号原值或昵称，仅保存参与者哈希摘要、日期、类型、去重摘要和当次配置快照。哈希摘要不等于不可逆匿名化，SQLite也不是加密存储；请妥善保护运行数据。管理员页面可删除事件及其模型计算贡献。留存模型合计包含所有已记录用户；建议配置白名单限制参与角色状态的私聊用户。插件通过宿主 llm.generate 调用所配置的模型，近期私聊正文会进入该模型请求，并可能进入宿主自己的请求日志；本插件数据库不保存原文。不发送聊天消息、不回溯旧聊天。授权状态上下文也会进入宿主所配置的LLM请求。

## 开发与验证

源码结构：`cycle.py`负责周期日期，`events.py`负责自述规则、历史与留存模型，`pregnancy.py`负责妊娠状态生命周期，`plugin.py`适配宿主API与上下文钩子，`webui/index.html`为管理页面。

完整测试需使用装有当前 MaiBot SDK 的运行环境：

```bash
python -m unittest discover -s tests -v
```

未安装SDK时可单独执行纯逻辑测试：

```bash
python -m unittest discover -s tests -p test_cycle.py -v
python -m unittest discover -s tests -p test_pregnancy.py -v
```

Windows环境若缺少IANA时区数据，需要在开发虚拟环境中安装 `tzdata`。后端测试覆盖周期计算、存储、上下文提取校验、并发去重、人工纠正及妊娠幂等性；验证结果以发布记录为准。测试使用临时数据库，不依赖或分发真实聊天记录、NAS配置或运行数据。

资料：[ACOG](https://www.acog.org/womens-health/faqs/fertility-awareness-based-methods-of-family-planning)、[NHS](https://www.nhs.uk/conditions/periods/fertility-in-the-menstrual-cycle/)。资料支持周期常识，不支持任何留存模型的参数。
